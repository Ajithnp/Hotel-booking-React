# Hotel Booking UI Practice

This is a practice project for building UIs using React.

## Tech Stack
- React 19
- Vite
- Tailwind CSS v4
- React Router DOM
- Clerk (Authentication)

## Project Structure
- `src/components`: Reusable UI components
- `src/pages`: Main page layouts (Home, Room List, Room Details, Dashboard, etc.)
- `src/App.jsx`: Main application component with routing

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.
